# tomob 영업 스크립트 — 최종 전달본

작성일: 2026-07-13  
포지션: 요청을 대기열에 등록하고 플랜별 동시 진행 수에 맞춰 이용하는 월 구독형 외부 웹 제작팀  
핵심 오퍼: 신규 고객 첫 요청 1건 무료

---

## 1. 영업자가 먼저 이해할 내용

### tomob의 한 줄 정의

> tomob은 요청을 대기열에 등록하고, 플랜별 동시 진행 슬롯에 맞춰 순서대로 제작하는 월 구독형 외부 웹 제작팀입니다.

### 고객이 얻는 가치

- 웹 작업이 생길 때마다 새 외주 업체를 찾고 견적을 받을 필요가 없습니다.
- 필요한 작업은 대기열에 등록하고, 플랜별 동시 진행 수에 맞춰 순서대로 맡길 수 있습니다.
- 첫 요청 1건을 무료로 경험한 뒤 구독 여부를 결정할 수 있습니다.
- 전체 홈페이지 구축이나 복잡한 기능 개발은 별도 견적으로 진행할 수 있습니다.

### 1차 통화의 목표

첫 통화에서 바로 계약을 끝내려 하지 않습니다. 아래 항목을 확보하면 성공입니다.

1. 현재 필요한 웹 작업 확인
2. 사이트 또는 쇼핑몰 링크 확보
3. 첫 요청 무료 제작에 대한 관심 확인
4. 상담 및 자료 수신 동의 확보

## 2. 서비스와 가격

| 플랜 | 월 요금 | 동시 진행 수 | 기본 대상 |
|---|---:|---:|---|
| Starter | 79만 원 | 1건 | 가끔 웹 작업이 필요한 업체 |
| Growth | 149만 원 | 2건 | 매달 랜딩·쇼핑몰 개선이 필요한 업체 |
| Studio | 249만 원 | 3건 | 광고·이벤트·프로모션이 잦은 브랜드 |

정상 가격:

- Starter: 월 99만 원
- Growth: 월 179만 원
- Studio: 월 299만 원

79만 원 / 149만 원 / 249만 원은 초기 파트너 가격이며, 적용 종료 시점은 tomob 담당자가 별도로 안내합니다.

공통 조건:

- 부가세 별도
- 최소 계약기간 없음
- 월 단위 이용
- 요청은 대기열에 등록하고 플랜별 동시 진행 수만 제한
- 작업 1건이 완료되면 대기열의 다음 요청 진행
- 동일 범위 수정 1회 포함
- 수정 중인 작업은 완료 전까지 진행 슬롯 1개 사용
- 방향 변경과 범위 추가는 새로운 요청 또는 별도 견적으로 처리
- Studio는 우선 제작 적용
- 월 요청 개수제가 아니므로 미사용 요청 이월 개념 없음

기본 전달 일정:

- 간단한 배너·팝업·섹션 수정: 48시간 내 1차 전달 목표
- 랜딩페이지·이벤트 페이지: 범위 확인 후 개별 일정 안내
- 자료 전달 지연, 범위 변경, 외부 연동 작업: 별도 일정 산정

### 요청 1건의 예시

- 광고·서비스 랜딩페이지 1개
- 이벤트·프로모션 페이지 1개
- 홈페이지 섹션 1~2개 개선
- 쇼핑몰 메인 일부 개선
- 상품 상세페이지 구성 리디자인 1건
- 배너·팝업·CTA 영역 제작
- 간단한 문의 연결형 페이지 1개

### 별도 견적 범위

- 홈페이지·쇼핑몰 전체 신규 구축
- 결제, 회원가입, 로그인, 예약 기능
- 복잡한 DB와 관리자 페이지
- 고도화된 게임·3D·인터랙티브 기능
- 상품 대량 등록
- 촬영, 전체 브랜딩, 대규모 카피라이팅
- 광고 운영 대행
- 무제한 수정

영업자는 가격 할인, 최종 범위, 납기일을 임의로 확정하지 않습니다.

## 3. 첫 요청 1건 무료 운영 기준

### 고객 안내 문구

> 신규 고객은 첫 요청 1건을 무료로 제작받고, 결과를 확인한 뒤 월 구독 여부를 결정할 수 있습니다.

### 무료 요청에 포함되는 범위

- 위 `요청 1건의 예시` 중 한 가지
- 랜딩·이벤트 페이지는 표준형 단일 페이지, 최대 5개 섹션
- 고객이 제공한 로고, 이미지, 제품·서비스 자료 사용
- 기본 반응형 제작
- 기본 문구 정리
- CTA, 카카오톡, 전화 또는 간단한 문의 연결
- 수정 1회
- 기본 미리보기 또는 합의된 환경의 기본 배포

### 무료 요청에서 제외되는 범위

- 전체 홈페이지나 쇼핑몰 구축
- 결제, 회원, 예약, 복잡한 폼·DB·관리자 기능
- 고급 3D, 게임, 복잡한 애니메이션
- 브랜드 전략, 촬영, 전체 카피 기획
- 유료 이미지·폰트·플러그인·서버 등 외부 비용
- 추가 페이지와 두 번째 요청
- 2회 이상의 수정

### 무료 요청 적용 조건

- 업체당 최초 1회만 적용합니다.
- 실제 운영 중인 제품, 서비스 또는 프로모션이 있어야 합니다.
- 제작에 필요한 자료를 제공해야 합니다.
- 작업 범위 확인을 위한 짧은 상담이 필요합니다.
- 무료 요청 완료 후 구독은 선택이며 강제하지 않습니다.
- 제작물을 tomob 포트폴리오로 공개하는 조건은 고객과 사전에 별도로 합의합니다.

무료라는 이유로 범위를 넓히거나, 포함되지 않은 기능을 현장에서 약속하지 않습니다.

## 6. 관심을 보였을 때 TOMOB Seed 연결

영업자는 상세 요구사항을 받아 적지 않습니다. 링크 수신 의사와 채널만 확인하고 TOMOB Seed로 연결합니다.

```text
감사합니다. 필요한 작업과 자료를 직접 입력하실 수 있는
TOMOB Seed 신청 링크를 보내드리겠습니다.

문자와 카톡 중 어디로 받아보시는 것이 편하실까요?
지금 바로 입력 가능하실까요, 아니면 편하실 때 확인하실까요?

입력을 완료하시면 제작 담당자에게 바로 알림이 전달되고,
내용을 확인한 뒤 1차 제작을 진행합니다.
완성본도 같은 Seed 안에서 확인하실 수 있습니다.
```

## 9. 최소 통화 기록과 TOMOB Seed 연결 기준

영업자의 업무는 관심도 판정과 TOMOB Seed 링크 발송까지입니다. 사이트·필요 작업·일정·보유 자료는 고객이 Seed에서 직접 입력합니다.

| 항목 | 필수 여부 | 기록 내용 |
|---|---:|---|
| 업체명 | 필수 |  |
| 담당자명·직책 | 권장 | 확인 가능한 경우 |
| 연락처 | 필수 |  |
| 링크 수신 채널 | 필수 | 문자 / 카톡 / 이메일 / 미동의 |
| 관심도 | 필수 | 상 / 중 / 하 / 제외 |
| Seed 링크 상태 | 필수 | 발송 완료 / 발송 예정 / 수신 거부 |
| 후속 연락 가능 시간 | 권장 | 약속한 경우만 기록 |
| 통화 메모 | 필수 | 관심 반응과 후속 약속만 간단히 기록 |
| 담당 영업자 | 필수 |  |

### 관심도 기준

- **상:** Seed 링크를 받았고 곧바로 또는 정해진 시간에 입력할 의사가 있음
- **중:** Seed 링크 수신에는 동의했지만 입력 시점은 미정
- **하:** 지금은 작업 계획이 없고 향후 연락이나 링크 보관에만 동의
- **제외:** 링크 수신 거부, 연락 금지 요청, 정보 불일치, 서비스 대상이 아님

고객이 TOMOB Seed에 정보를 입력하면 제작 담당자에게 텔레그램 알림이 전달되고, 담당자가 범위를 확인해 제작한 뒤 1차본을 Seed에 등록합니다. 고객은 같은 Seed 안에서 결과를 확인합니다.

단순 연락처 확보나 링크 발송만으로 유료 전환 또는 수당 대상으로 확정하지 않습니다.

## 10. 영업 수당·정산 기준

| 구분 | 기준 |
|---|---:|
| 영업 파트너 | 유료 전환 후 고객 실제 수금액의 15% |

### 정산 원칙

- 첫 무료 요청에는 수당이 발생하지 않습니다.
- 유료 구독 또는 별도 구축 계약의 실제 입금 완료 금액을 기준으로 합니다.
- 부가세, 환불, 취소, 미수금은 정산 대상에서 제외합니다.
- 분할 입금은 실제 입금된 회차별로 정산합니다.
- 동일 고객이 중복 접수되면 최초 유효 리드를 기준으로 확인합니다.
- 유지 구독에 대한 반복 수당은 영업 파트너 합의서의 확정 조건을 따릅니다.
- 가격 할인, 작업 범위, 납기, 환불 조건을 영업자가 임의로 확정하지 않습니다.

실제 계약서 또는 영업 파트너 합의서의 확정 내용이 이 문서보다 우선합니다.

## 11. 영업자가 절대 하지 말아야 할 말

- 무료로 홈페이지 전체를 만들어드립니다.
- 무료 요청에 복잡한 기능이나 무제한 수정이 포함됩니다.
- 매출이나 전환율을 반드시 올려드립니다.
- AI로 금방 만들기 때문에 저렴합니다.
- 어떤 작업이든 다 가능합니다.
- 오늘 결정하면 임의로 할인해드리겠습니다.
- 범위를 확인하지 않고 제작 일정이나 완료일을 약속합니다.
- 확인하지 않은 포트폴리오와 성과를 tomob의 실적으로 말합니다.
- 고객이 거절했는데도 반복 연락하거나 자료를 발송합니다.

## 12. 통화 종료 체크리스트

- [ ] 웹 제작 서비스에 대한 관심 여부를 확인했는가
- [ ] Seed 링크 수신 채널을 확인했는가
- [ ] Seed 링크 발송 상태를 기록했는가
- [ ] 첫 요청 무료 범위를 과장하지 않았는가
- [ ] 상세 요구사항은 TOMOB Seed에서 고객이 직접 입력한다고 안내했는가
- [ ] 후속 연락 방법과 시간을 확인했는가
- [ ] 관심도와 통화 메모를 기록했는가
- [ ] 연락 거부 고객을 제외 처리했는가

## 13. 영업자가 기억할 핵심 문장

> 첫 요청 1건은 무료이고, 결과를 확인한 뒤 구독 여부를 결정할 수 있습니다.

> 무료 요청도 작업 범위와 수정 횟수가 정해져 있습니다.

> 가격, 범위, 일정은 tomob 담당자가 확인 후 확정합니다.
