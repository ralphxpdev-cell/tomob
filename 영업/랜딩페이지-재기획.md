# tomob 공식 랜딩페이지 재기획

> 기준 문서: `빌드업.md`  
> 확인 파일: `app/page.tsx`, `app/globals.css`, `app/layout.tsx`, `index.html`  
> 목적: 기존 tomob 랜딩을 새 포지셔닝인 "광고 랜딩페이지 + 리드관리 시스템 + 인터랙티브 DB 수집 웹 에이전시"에 맞게 재구성한다.

---

## 1. 현재 랜딩 진단

현재 라이브 소스는 `index.html`이 아니라 `app/page.tsx`입니다.  
루트 `index.html`은 예전 정적 파일이고, 실제 배포 반영은 Next.js 앱 구조에서 이루어집니다.

### 현재 메시지

- 브랜딩 · 웹사이트 · 마케팅 에이전시
- 매출이 막혔다면 방향성부터 봅니다
- 포트폴리오, 후기, Why TOMOB, 서비스, 프로세스, 카카오 상담 CTA

### 현재 강점

- 비주얼 임팩트가 있음
- 기존 포트폴리오와 후기가 있어 신뢰 요소가 있음
- 카카오 상담 CTA가 명확함
- 브랜드 톤은 어느 정도 잡혀 있음

### 현재 문제

- 새 사업 방향인 리드관리, DB 수집, 광고 랜딩 시스템이 첫 화면에서 보이지 않음
- "방향성" 메시지는 좋지만, 고객 입장에서는 어떤 문제를 해결해주는지 즉시 알기 어려움
- 서비스 항목이 브랜딩, SNS, 마케팅, AX 등으로 넓게 퍼져 있어 고단가 웹 구축형 에이전시 포지션이 흐려짐
- 무료 점검 CTA가 있지만, 무엇을 점검해주는지 구체성이 약함
- 콜영업 후 방문한 고객에게 "내가 지금 신청해야 하는 이유"가 약함
- 리드 수집 폼이 없고 카카오톡 외 전환 경로가 부족함

## 2. 새 랜딩의 핵심 목표

이번 랜딩은 예쁜 회사 소개 페이지가 아니라 영업 퍼널의 중간 지점이어야 합니다.

### 1차 목표

무료 진단 신청 확보

### 2차 목표

사이트/스토어 URL 확보

### 3차 목표

Landing System 또는 Lead System 상담 전환

### 4차 목표

고객이 tomob을 "홈페이지 제작사"가 아니라 "고객 DB가 쌓이는 웹 시스템 구축사"로 인식하게 만들기

---

## 3. 새 포지셔닝

### 한 줄 정의

> tomob은 광고비가 문의와 고객 DB로 이어지도록 랜딩페이지부터 리드관리 시스템까지 구축하는 AI 웹 에이전시입니다.

### 더 짧은 영업형 문장

> 광고는 하는데 문의가 적다면, 랜딩과 리드관리 구조부터 다시 봐야 합니다.

### 차별화 문장

> tomob은 단순히 홈페이지를 만드는 것이 아니라, 광고 유입 고객이 문의하고, DB로 저장되고, 상담 상태까지 관리되는 웹 시스템을 구축합니다.

---

## 4. 추천 마케팅 퍼널

### 퍼널 전체 흐름

1. 콜영업 / 카톡 / 문자 / 소개자료 발송
2. tomob 랜딩페이지 방문
3. 문제 공감: 광고비는 쓰는데 문의와 DB가 쌓이지 않음
4. 해결 구조 이해: 랜딩페이지 + 문의폼 + DB + 상담관리
5. 무료 진단 신청
6. tomob이 사이트/스토어 분석
7. 무료 진단 리포트 전달
8. 15분 상담
9. Landing System 또는 Lead System 견적 제안
10. 계약 및 제작
11. 유지보수/개선 구독 전환

### 랜딩에서 맡아야 할 역할

- 콜영업으로 생긴 약한 관심을 신뢰로 바꾼다.
- "무료 진단"이 부담 없는 첫 행동처럼 보이게 한다.
- 서비스 범위를 너무 넓게 보여주지 않고, 랜딩/리드관리 중심으로 좁힌다.
- 고객이 직접 자기 상황을 선택하게 만든다.

### CTA

## 5.2 Problem

### 제목

> 광고는 하는데, 고객은 어디서 놓치고 있나요?

### 문제 항목

- 광고 클릭은 있는데 문의가 적다
- 랜딩페이지가 없거나 상세페이지로만 광고를 받는다
- 문의가 카톡, 전화, 엑셀에 흩어진다
- 고객 DB가 쌓이지 않는다
- 상담 상태를 누가 어디까지 했는지 모른다
- 이벤트 참여 데이터가 남지 않는다
- 홈페이지는 있지만 영업 도구로 작동하지 않는다

### 의도

고객이 "내 얘기다"라고 느끼게 만드는 섹션입니다.

## 5.3 Diagnosis Offer

### 제목

> 먼저 무료로 진단해드립니다.

### 설명

> 지금 운영 중인 사이트나 스마트스토어를 기준으로 광고 랜딩, 문의 전환, 리드 수집 구조에서 개선할 수 있는 지점을 정리해드립니다.

### 무료 진단 포함 항목

- 현재 사이트 문제점 3개
- 광고 유입을 받을 랜딩 구조 제안
- 문의폼/CTA 개선 방향
- 고객 DB 수집 가능성
- 필요한 구축 범위 안내

### CTA

- 우리 회사 랜딩 구조 진단받기

---

## 5.4 Solution

### 제목

> tomob은 고객 유입부터 리드관리까지 하나의 흐름으로 연결합니다.

### 5단계 구조

1. 광고 유입을 받는 랜딩페이지
2. 문의/상담/구매 CTA 설계
3. 고객 정보 DB 저장
4. 상담 상태 관리
5. 알림, 유입경로, 운영 개선

### 보조 확장

> 필요하면 퀴즈, 룰렛, 랭킹, 미니게임 같은 참여형 콘텐츠로 고객 DB를 수집하는 구조까지 만들 수 있습니다.

---

## 5.5 Services

### 제목

> 필요한 만큼 작게 시작하고, 성과가 보이면 확장합니다.

### 상품 구성

#### 1. Landing System

광고용 랜딩페이지 구축  
예상 범위: 200만 원 ~ 300만 원 / 1~2주

#### 2. Lead System

랜딩페이지 + 문의 DB + 관리자 페이지  
예상 범위: 400만 원 ~ 700만 원 / 2~3주

#### 3. Interactive Lead Game

퀴즈, 룰렛, 랭킹, 이벤트 참여형 DB 수집 콘텐츠  
예상 범위: 500만 원 ~ 1500만 원 / 3~5주

#### 4. 3D Brand Landing

Three.js 기반 브랜드/캠페인 랜딩페이지  
예상 범위: 700만 원 ~ 2000만 원 / 3~6주

#### 5. Mini SaaS Build

상담, 예약, 견적, 고객 관리용 맞춤형 미니 SaaS  
예상 범위: 800만 원 ~ 3000만 원 / 4~8주

### 표시 방식

가격은 "예상 범위"로 작게 노출합니다.  
메인 CTA는 여전히 "무료 진단"으로 유지합니다.

## 10. MVP 개발 범위

### 1차 개편

- `app/page.tsx` 랜딩 카피와 섹션 구조 교체

### 2차 개편

- Supabase leads 테이블 연결
- `/thanks` 페이지 추가
- `/admin` 리드 목록 페이지 추가
- 상태값 변경과 메모 입력

### 3차 개편

- 유입경로 기록
- 이메일/슬랙 알림
- 서비스별 문의 분류
- 간단한 통계 카드

## 11. 권장 첫 작업

바로 전체 시스템을 만들기보다, 먼저 공식 랜딩 카피와 구조를 새 포지셔닝으로 바꾸는 것이 좋습니다.

### 첫 작업 범위

1. Hero 카피 교체
2. Problem 섹션 신설
3. Diagnosis Offer 섹션 신설
4. Services를 새 상품 라인업으로 교체
5. Process를 무료 진단 기반 흐름으로 교체
6. Final CTA를 무료 진단 중심으로 교체

이후 폼과 Supabase 리드 저장을 붙이면 됩니다.
