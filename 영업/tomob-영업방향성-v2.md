# tomob 영업 방향성 v2

> 목적: tomob의 영업 포지션, 상품 구조, 가격 방향, 영업 메시지를 다시 정리한 문서입니다.  
> 기준: "AI"를 전면에 내세우지 않고, 빠른 제작력과 월간 웹 제작팀 포지션을 중심으로 잡습니다.

---

## 1. 결론

tomob은 단순 홈페이지 제작사나 저가 랜딩페이지 제작사가 아니라,  
브랜드와 업체가 매달 필요한 웹 제작물을 빠르게 맡길 수 있는 **월간 웹 제작팀**으로 포지셔닝합니다.

### 한 줄 정의

> tomob은 홈페이지, 쇼핑몰, 랜딩페이지, 이벤트 페이지를 요청 단위로 빠르게 제작하는 월간 웹 제작팀입니다.

### 더 쉬운 설명

> 필요할 때마다 외주 견적을 새로 받지 않고, 월간 요청 단위로 웹 제작물을 맡길 수 있는 제작 파트너입니다.

---

## 2. 왜 이 방향인가

### 피해야 할 시장

- 저가 랜딩페이지 제작
- 단순 홈페이지 제작
- 일반 쇼핑몰 구축
- 무제한 수정 구독
- "AI로 저렴하게 만들어드립니다" 식의 딸깍형 포지션

이 시장은 이미 경쟁자가 많고, 가격 비교를 당하기 쉽습니다.

### tomob이 잡아야 할 시장

- 웹 제작물이 자주 필요한 업체
- 신제품, 이벤트, 프로모션을 자주 여는 브랜드
- 홈페이지나 쇼핑몰을 조금씩 개선해야 하는 업체
- 내부 디자이너/개발자가 없어서 빠른 제작팀이 필요한 업체
- 매번 외주 견적을 받고 기다리는 것이 번거로운 업체

---

## 3. 핵심 포지션

### 기존 약한 표현

> 랜딩페이지 제작합니다.

> 홈페이지 제작합니다.

> 쇼핑몰 제작합니다.

### 새 표현

> 매달 필요한 웹 제작물을 요청 단위로 빠르게 만들어드립니다.

> 홈페이지, 쇼핑몰, 랜딩페이지, 이벤트 페이지를 외부 제작팀처럼 맡길 수 있습니다.

> 한 번 만들고 끝나는 외주가 아니라, 필요한 순간마다 움직이는 월간 웹 제작팀입니다.

---

## 4. 주요 제작 범위

tomob이 메인으로 가져갈 제작 범위는 아래 네 가지입니다.

### 1. 홈페이지

- 회사소개 페이지
- 서비스 소개 페이지
- 기존 홈페이지 섹션 개선
- 브랜드 소개 페이지
- 포트폴리오/사례 페이지

### 2. 쇼핑몰

- 쇼핑몰 메인 섹션 개선
- 상품 상세페이지 구성 개선
- 프로모션 배너/섹션 제작
- 신제품 소개 페이지
- 이벤트/기획전 페이지

### 3. 랜딩페이지

- 광고용 랜딩페이지
- 서비스 소개 랜딩
- 이벤트 신청 랜딩
- 상담/문의 유도 페이지
- 카카오/전화/폼 연결형 페이지

### 4. 이벤트/참여형 웹

- 이벤트 페이지
- 퀴즈형 페이지
- 룰렛/뽑기형 이벤트
- 간단한 참여형 콘텐츠
- 브랜드 캠페인용 인터랙티브 페이지

---

## 5. 핵심 차별점

### 1. 빠른 제작

웹 제작물을 오래 기다리지 않고 빠르게 받아볼 수 있습니다.

### 2. 요청 단위 운영

필요한 작업을 한 번에 크게 맡기는 것이 아니라, 월 1개, 2개, 3개 요청 단위로 맡길 수 있습니다.

### 3. 넓지만 연결된 범위

홈페이지, 쇼핑몰, 랜딩페이지, 이벤트 페이지는 모두 업체가 영업과 판매를 위해 반복적으로 필요로 하는 웹 제작물입니다.

### 4. 부담 낮은 시작

최소 계약 기간 없이 월 단위로 시작할 수 있습니다.

### 5. 외부 제작팀처럼 사용

고객은 매번 새 외주를 찾지 않고, tomob에 필요한 웹 작업을 요청할 수 있습니다.

---

## 6. 가격 구조 방향

가격은 "랜딩 1개 얼마"가 아니라 **월간 요청권** 기준으로 안내합니다.

### Starter

월 79만 원

- 월 1개 요청
- 랜딩 1페이지 / 홈페이지 섹션 수정 / 쇼핑몰 섹션 개선 / 이벤트 페이지 중 1개
- 수정 1회 포함
- 월 단위 이용

### Growth

월 149만 원

- 월 2개 요청
- 홈페이지, 쇼핑몰, 랜딩, 이벤트 페이지 조합 가능
- 간단한 폼 연결 가능
- 수정 각 1회 포함
- 월 단위 이용

### Studio

월 249만 원

- 월 3개 요청
- 랜딩, 쇼핑몰 개선, 이벤트 페이지, 간단한 참여형 콘텐츠 가능
- 우선 제작
- 수정 각 1회 포함
- 월 단위 이용

---

## 7. 요청 1개 기준

요청 1개는 아래 정도의 작업으로 제한합니다.

- 랜딩페이지 1개
- 이벤트/프로모션 페이지 1개
- 홈페이지 섹션 1~2개 개선
- 쇼핑몰 메인 섹션 일부 개선
- 상품 상세페이지 구성 리디자인 1건
- 배너/팝업/CTA 영역 제작
- 간단한 문의 연결형 페이지 1개

---

## 8. 별도 견적 기준

아래 작업은 구독 요청 범위에 포함하지 않고 별도 견적으로 안내합니다.

- 홈페이지 전체 신규 구축
- 쇼핑몰 전체 신규 구축
- 결제 기능
- 회원가입/로그인
- 예약 시스템
- 복잡한 DB/관리자 페이지
- 고도화된 게임 로직
- 상품 대량 등록
- 광고 운영 대행
- 촬영/상세 브랜드 전략
- 무제한 수정

---

## 9. 무료 제공 무기

영업에서는 "무료 진단"보다 더 쉽게 말할 수 있는 **1회 무료 요청 상담**을 사용합니다.

### 무료 제공 표현

> 현재 홈페이지나 쇼핑몰을 보고, 어떤 웹 제작물이 먼저 필요한지 1회 무료로 정리해드립니다.

### 무료 제공 범위

- 현재 사이트/쇼핑몰 확인
- 필요한 웹 제작물 우선순위 정리
- 랜딩, 이벤트 페이지, 쇼핑몰 개선 중 적합한 방향 제안
- 구독 플랜 추천

### 주의

무료로 실제 제작물을 무조건 제공한다고 말하지 않습니다.  
무료는 "진단/방향 정리/요청 범위 상담"으로 제한합니다.
